# 密码生成器

**确定性密码派生工具** —— 不存储密码，通过 SHA-256 加密算法从你输入的信息中派生出强密码。

同一输入 + 相同设置 = 永远一样的密码。你只需记住一个主密码，就能为每个网站生成独立的高强度密码。

## 特性

- **纯离线**：所有计算在本地完成，不联网、不上传
- **确定性**：相同输入永远得到相同结果，密码不存于任何地方
- **强密码**：90+ 可打印字符空间，支持大写字母 + 特殊符号
- **策略兼容**：勾选的每类字符必定至少出现一次，满足各类网站密码要求
- **跨平台**：Python（Windows/macOS/Linux）和 HTML（任意浏览器，含手机）

## 快速开始

### 网页版（推荐，全平台）

直接用浏览器打开 `index.html`，无需安装任何东西。手机、平板、电脑都能用。

### Python 版

```bash
python password_generator.py
```

依赖：Python 3.6+，仅用标准库（tkinter + hashlib），无需 pip install。

## 使用方法

1. 在「输入信息」中填入主密码 + 网站标识（如 `MySecret+github`）
2. 设置密码长度（建议 12–16 位）
3. 根据需要勾选「包含大写字母」和「包含特殊符号」
4. 点击「生成密码」，复制使用

## 加密原理

| 环节 | 说明 |
|------|------|
| SHA-256 哈希 | 对输入信息做 SHA-256，得到 256 位输出。相同输入永远相同哈希 |
| 字符集映射 | 每个哈希字节（0–255）对字符集大小取模，映射到可打印字符 |
| 字节流扩展 | 需要更多字符时，通过追加计数器反复哈希（`input\|0`, `input\|1`...） |
| 类别锚点 | 从勾选的每类字符中各取一个"锚点"，保证每类至少出现一次 |
| Fisher-Yates 洗牌 | 用哈希导出的序列做确定性洗牌，打散锚点位置 |

## 字符集

```
小写: abcdefghijkmnopqrstuvwxyz  (去除 l)
大写: ABCDEFGHJKLMNPQRSTUVWXYZ   (去除 I)
数字: 23456789                    (去除 0,1)
符号: !@#$%^&*()-_=+[]{}|;:,.<>?
```

去掉易混淆字符（l/I/1/O/0），字符集共约 80 个字符。

## 安全建议

- 输入信息中应包含足够长的、仅你知晓的主密码
- 为不同网站使用不同标识（如 `+github`、`+google`）
- 即使生成器是确定性的，也不要将主密码明文保存
